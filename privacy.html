The short version

PageSpeed Sampler is a single HTML page. There is no account, no sign-in and no analytics, and your settings never leave your browser. One thing does leave: the URLs you ask to measure, because a backend has to pass them to Google on your behalf so that you do not need a Google Cloud account of your own. It also sees a salted hash of your IP address, used only to count a daily allowance. It never sees your name, your email or a history of what you looked at, and if you supply your own API key it is not involved at all.

Who this covers#

This policy applies to PageSpeed Sampler, published at pagespeed.jakelabate.com and maintained by Jake Labate, SEO Consultant.

What is stored, and where#

The tool saves your settings in your browser's localStorage so you do not have to retype them. That includes the names and URLs of the sites you enter, your sampling preferences, and your PageSpeed Insights API key if you chose to supply one. The key field is optional and empty by default.

This data never leaves your browser. It is not synced, not backed up, and not readable by anyone else. Clearing your browser's site data for this domain deletes all of it.

What is sent, and to whom#

The tool makes requests to third parties on your behalf. Unless you supply your own API key, those requests go through a small backend run by Jake Labate, described in the next section, so that you do not need a Google Cloud account to use this.

  • Chrome UX Report API. The instant read sends each origin you enter to chromeuxreport.googleapis.com, with your API key if you supplied one and otherwise through the backend below, and gets back that origin’s real-user Core Web Vitals. It is a lookup of data Google already holds; nothing about your visit is added to it.
  • Google PageSpeed Insights API. Each URL you choose to measure is sent to pagespeedonline.googleapis.com, along with your API key if you supplied one. This is how the measurement happens. Google's handling of those requests is governed by the Google Privacy Policy.
  • The sites you measure. To find a sitemap, the tool requests robots.txt and common sitemap paths from the sites you enter, directly from your browser.
  • Public CORS proxies. Most sites do not allow a browser to read their sitemap cross-origin. When a direct request is blocked, the tool retries through a public proxy so it can read the file. The proxies it may use are allorigins, codetabs, corsproxy.io, isomorphic-git and thingproxy. Only the public sitemap URL is passed to them; your API key and your settings are never sent to a proxy.
  • This deployment’s own backend. A Cloudflare Worker run by Jake Labate does two jobs. It fetches sitemaps, ahead of any public proxy, because sites behind a WAF block the public ones by address. And, when you have not supplied your own API key, it makes the PageSpeed and Chrome UX Report calls for you using keys it holds, so the tool is usable without a Google Cloud account. What it receives is set out in the next section. Your own API key, if you enter one, is never sent to it: the backend is bypassed entirely and your browser talks to Google directly.
  • Google Sheets and Drive. Only if you choose to create a Google Sheet. See the next section.

What the backend sees#

This section applies only when you have not entered your own API key. With a key in the field the backend is bypassed and none of it happens.

The URLs you measureIt has to receive them, because it is the thing that asks Google to measure them. They are public URLs on sites you chose to enter.
A hash of your IP addressUsed to meter a daily allowance so that one visitor cannot exhaust the shared quota. Your raw IP address is never stored. What is stored is a salted one-way hash of it and a running count for the day, both of which expire automatically once the day ends.
Nothing elseNo account, no cookie, no name, no email, no browser fingerprint, and no record of which sites a given visitor looked at. The stored counter is a number, not a history.

Measurement results are cached for six hours so a page already measured is not measured again. The cache is keyed on the URL and shared between all visitors, so a result you receive may have been produced by someone else’s request and yours may be reused for someone else. What is cached is a public page’s public performance data, and it is not linked to whoever asked for it.

Cloudflare operates the network the backend runs on and processes requests under its own terms. The API keys the backend uses belong to Jake Labate, and the quota they spend is his.

Google account access#

The Google Sheets export is optional and off unless you configure it. When you use it, the tool requests a single scope: https://www.googleapis.com/auth/drive.file.

That scope grants access only to files this application itself creates. It cannot list, read, open, modify or delete any other file in your Google Drive, and it cannot see that those other files exist. The tool uses it for exactly one thing: creating a new spreadsheet containing your measurement results, in your own Drive, owned by you.

The resulting access token is held in the memory of the browser tab for the duration of that action and is never written to storage or transmitted anywhere other than Google's own API endpoints.

PageSpeed Sampler's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Data obtained through Google APIs is not transferred to any third party, is not used for advertising, and is not read by any human.

You can revoke this access at any time at myaccount.google.com/permissions. Spreadsheets already created stay in your Drive and remain yours.

Analytics and tracking#

There are none. No analytics, no tag manager, no advertising, no cookies, no fingerprinting, no error reporting service. The page loads two external scripts, both only when needed: the ExcelJS library from cdnjs for the Excel export, and Google Identity Services for the Sheets sign-in.

Hosting#

The page is served as a static file by GitHub Pages. GitHub receives standard web server request logs, such as IP address and user agent, as it does for any page it serves. This is outside the tool's control and is covered by the GitHub Privacy Statement.

Children#

This is a professional technical tool. It is not directed at children and collects nothing from anyone.
